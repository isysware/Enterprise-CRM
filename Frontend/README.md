# Enterprise Lead CRM

Multi-portal Enterprise Lead Management CRM with Role-Based Access Control (RBAC), Follow-Up Tracker, Monthly Calendar, Converted Clients, Performance Analytics in PKR, Proposal Builder, and System Administration.

## Overview
This frontend application provides the complete CRM workspace, interface components, and business workflows using a local mock runtime.

- **Frontend Architecture**: Next.js App Router, TypeScript, Tailwind CSS, shadcn/ui foundation, Poppins font
- **Data & Runtime**: In-memory and local mock runtime with comprehensive role-based access control (RBAC)
- **AI Assistant Interface**: Structured client boundary and frontend contract ready for backend connection
- **Database & Backend Integration**: Backend API endpoints, database persistence, and secure server-side AI integration will be added in a subsequent phase.

## Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Run type check / linting
npm run lint

# Build for production
npm run build
```
